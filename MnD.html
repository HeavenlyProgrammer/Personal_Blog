Elektronika Digital Dasar

Mengenal komponen penting dalam sistem logika digital

Apa itu Multiplexer (MUX)?

Multiplexer atau sering disingkat MUX adalah rangkaian logika kombinasional yang berfungsi untuk memilih satu data input dari beberapa input yang tersedia, lalu meneruskannya ke satu jalur output.

Dalam sistem digital, MUX sering digunakan ketika banyak sumber data harus berbagi satu jalur pengiriman. Dengan adanya multiplexer, sistem menjadi lebih efisien karena tidak memerlukan banyak kabel atau jalur output.

Konsep Utama Multiplexer:
Many to One (Banyak Input ke Satu Output)

Pemilihan input yang akan diteruskan ke output dikendalikan oleh select line atau jalur selektor. Kombinasi logika pada select line inilah yang menentukan input mana yang sedang aktif.

Contohnya, pada MUX 4:1 terdapat 4 input data, 2 select line, dan 1 output. Setiap kombinasi select line akan memilih satu input tertentu.

Apa itu Demultiplexer (DEMUX)?

Demultiplexer atau DEMUX merupakan kebalikan dari multiplexer. Rangkaian ini berfungsi untuk mendistribusikan satu data input ke salah satu dari banyak jalur output.

Demultiplexer sering digunakan ketika satu sumber data perlu dikirim ke beberapa tujuan yang berbeda, namun hanya satu tujuan yang aktif dalam satu waktu.

Konsep Utama Demultiplexer:
One to Many (Satu Input ke Banyak Output)

Sama seperti MUX, DEMUX juga menggunakan select line untuk menentukan output mana yang akan menerima data. Output yang tidak dipilih akan berada pada kondisi tidak aktif.

Perbedaan Multiplexer dan Demultiplexer

Aspek Multiplexer (MUX) Demultiplexer (DEMUX)
Fungsi Utama Memilih satu data dari banyak input Mendistribusikan data ke salah satu output
Arah Aliran Data Banyak Input → Satu Output Satu Input → Banyak Output
Peran Select Line Menentukan input yang aktif Menentukan output yang aktif
Contoh Aplikasi Penghematan jalur data Distribusi sinyal

Kesimpulan

Multiplexer dan demultiplexer merupakan komponen dasar yang sangat penting dalam elektronika digital. MUX berperan sebagai pemilih data, sedangkan DEMUX bertugas sebagai pendistribusi data.

Pemahaman yang baik terhadap kedua rangkaian ini akan memudahkan dalam mempelajari sistem komputer, komunikasi data, serta perancangan rangkaian digital yang lebih kompleks.
